O programe Password Safe

Password Safe a šifrovací algoritmus Twofish, ktorý používa, boli pôvodne vyvinuté a sprístupnené verejnosti spoločnosťou Counterpane Labs a profesionálom v oblasti počítačovej bezpečnosti s menom Bruce Schneier (autor knihy Applied Cryptography a ďalších kníh, tvorca algoritmu Blowfish a zakladateľ spoločnosti Counterpane Internet Security).

Password Safe je teraz open source projekt hostovaný na GitHub a SourceForge. Najnovšie aktualizácie programu, dokumentáciu a novinky nájdete na adrese https://pwsafe.org.

Password Safe je voľne dostupný a distribuovaný s obmedzeniami stanovenými v štandarde Open Source Initiative (OSI) "Artistic License 2.0." Kópia tejto licencie je súčasťou inštalačného balíka Password Safe v súbore s názvom LICENSE.

Twofish je rýchla a bezplatná alternatíva k šifrovacím algoritmom AES, DES a IDEA. Podrobnosti o algoritme Twofish vrátane porovnania rýchlosti a rozsiahleho zoznamu produktov, ktoré používajú Twofish, sú k dispozícii na adrese https://www.schneier.com/twofish.html.

Najnovšie zmeny, opravy chýb a dokumentáciu nájdete v súboroch Readme.md, Changelog.txt a ReleaseNotes.md v inštalačnom balíku.

Všetky ostatné značky alebo názvy produktov sú ochrannými známkami príslušných spoločností. Neexistuje a ani nie je poskytovaná podpora a schválenie zo strany týchto spoločností.
